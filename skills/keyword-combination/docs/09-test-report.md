## 四、边界与已知限制

| 限制 | 说明 |
|---|---|
| 不含真实 KD 数据 | 脚本不联网，KD 区间为规则值；真实 KD 须用户从平台后台补（输出 `pending_data`） |
| 相关性判断 | 「无关类目词」依赖用户传入 `category_words_to_avoid`，脚本不自行判定语义 |
| 平台规则时效 | 字数上限与审核规则会调整，以平台官方最新公示为准 |
