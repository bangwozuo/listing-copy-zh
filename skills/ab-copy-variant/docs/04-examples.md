# 使用示例

以下示例的输入均为**真实可跑数据**，校验结果由 `scripts/variant_matrix.py` 实跑产生。

---

## 示例 1：同一卖点 4 个角度 + CTR 择优（本技能主场景）

**输入**（`examples/input.json`）：淘宝标题里「12 小时保温」的 4 个角度变体 + 一周 CTR 数据。

**输出**（实跑）：4 个变体两两 Jaccard 全部 < 0.3（同质化对 0）；
最小曝光 1900，实际每组约 2400 → 样本充足；B 版（场景代入）CTR 7.18%，
比最低的 C 版（5.08%）高 2.10pp > 阈值 2.0pp → **建议采用 B**。

**变体一览**：

| # | 角度 | 文案 |
|---|---|---|
| A | 理性功能 | 304不锈钢+真空层，12小时保温 |
| B | 场景代入 | 早上灌的热水，开完下午的会还是温的 |
| C | 疑问钩子 | 你的保温杯，撑得住一个工作日吗？ |
| D | 情感共鸣 | 忙到忘了喝水的人，更需要一杯温的 |

## 示例 2：同义换词被拦（同质化）

**输入**：

```json
{
  "platform": "淘宝",
  "variants": [
    {"角度": "理性功能", "文案": "304不锈钢真空保温杯，12小时长效保温"},
    {"角度": "数据实证", "文案": "304不锈钢真空保温杯，长效保温12小时"}
  ]
}
```

**输出**（实跑）：两句话只有语序差异，J(A,B) = **0.8** ≥ 0.6 →
🔴「两两 Jaccard < 0.6」不通过，判**同质化**（输出 `same_pairs: ["A-B(J=0.8)"]`）。

**整改方向**：换角度重写，而不是调语序。

| ❌ 同质化 | ✅ 换成「场景代入」角度 |
|---|---|
| 304不锈钢真空保温杯，长效保温12小时 | 早上灌的热水，开完下午的会还是温的 |

> J 值高不等于文案差，只说明**两者差异不足以支撑一次有意义的 A/B 实验**。

## 示例 3：样本不足不给结论（防过度解读）

**输入**：

```json
{
  "platform": "淘宝",
  "p_bar": 0.05,
  "delta": 0.02,
  "variants": [
    {"角度": "理性功能", "文案": "304不锈钢+真空层，12小时保温"},
    {"角度": "场景代入", "文案": "早上灌的热水，开完下午的会还是温的"}
  ],
  "metrics": {
    "A": {"曝光": 300, "点击": 22},
    "B": {"曝光": 320, "点击": 31}
  }
}
```

**输出**（实跑）：每组最小曝光 1900，实际仅 300/320 →
⚠️「样本不足（A、B < 1900），只报值不下结论」。
脚本**不会**因为 B 的 CTR 更高就下结论——这是 A/B 实验最常见的误判来源。

## 示例 4：多变量齐改（实验无效）

**输入**：

```json
{
  "brief": "同时改标题、主图和价格，看哪个卖点更好",
  "variants": [
    {"角度": "理性功能", "文案": "304不锈钢+真空层，12小时保温"},
    {"角度": "场景代入", "文案": "早上灌的热水，开完下午的会还是温的"}
  ]
}
```

**输出**（依 prompt 的单一变量原则）：判「实验无效」——
同时改了 ≥ 2 个变量，CTR 差异**不可归因**。
正确做法：冻结主图与价格，只改文案，跑满最小曝光后再判优。
