# 广告法合规预审

在文案定稿后、上架前，把会被平台**驳回、限流、处罚**的表述挑出来，
并给出**可直接替换的改法**。

不做的事：不写卖点、不写文案、不判断商品质量。只做审查。

## 能力描述

按四类规则做分级合规扫描，输出**可执行的整改清单**：

1. **绝对化用语**（《广告法》第九条）—— 最高级 / 排名 / 唯一性 / 级别 / 功效断言
2. **类目特有禁用表述** —— 化妆品、食品、保健品、医疗器械、母婴、教育、金融各有独立禁词表
3. **虚假与不正当竞争** —— 虚假促销、诱导评价（好评返现）、贬低竞品、未授权品牌词、专利虚标
4. **平台特有规则** —— 站外导流（二维码/微信号）、主图牛皮癣、资质公示缺失

判定分三级：🔴 红线（必须改）/ 🟡 警告（建议改）/ 🔵 提示（需补材料）。

## 输入规格

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `text` | string | ✅ | 待检文案（标题 + 副标题 + 卖点 + 详情页 + 图上文字，尽量给全） |
| `platform` | string | ⬜ | 淘宝 / 天猫 / 抖音 / 拼多多 / 小红书 / 通用；缺省按通用扫 |
| `category` | string | ⬜ | 化妆品 / 食品 / 保健品 / 医疗器械 / 母婴 / 教育 / 金融 |
| `rules` | string | ⬜ | 用户自定义词表或平台补充规则 |

## 输出规格

- `verdict`：总体判定（受检平台 / 文本量 / 三级计数 / 总体结论）
- `violations`：违规清单（级别 / 违规词 / 原文片段 / 命中规则 / 依据 / 修改建议）
- `suggestions`：整体修改建议（按规则族归并）

## 使用步骤

### 方式一：纯提示词（最快）

1. 打开任意 AI 工具（Coze / WorkBuddy / Dify / Claude / ChatGPT）
2. 把 `prompt.txt` **全文**粘贴为系统提示词
3. 提供 `text` + `platform`（可选 `category`、`rules`）
4. 得到分级违规清单与替换写法

### 方式二：带脚本（词表精确扫描 + 产出 Excel）

```bash
python3 <SKILL_DIR>/scripts/adlaw_scan.py --input input.json --outdir out
python3 <SKILL_DIR>/scripts/adlaw_scan.py --demo        # 无输入也能看效果
```

产物：

| 文件 | 内容 |
|---|---|
| `out/广告法预审清单.xlsx` | 违规清单（红线行标红）/ 需补材料 / 整体建议 / 汇总 |
| `out/adlaw_scan.json` | 机器可读结果，供智能体读取 |

**分工**：脚本做**词表精确扫描**（不漏、不猜）；模型做**语境判断与改法撰写**（脚本做不了的）。

## 边界（不做的事）

- ❌ 不编造违规项 —— 没有依据的词不得报违规
- ❌ 不提供规避审核的写法（谐音、拼音、拆字绕开检测）—— 属违规协助
- ❌ 不修改商品实质信息（价格、成分、规格的真实数值）
- ❌ 不评判商品质量，不构成法律意见
- ❌ 平台规则多变，本预审**不能替代**平台官方审核结果
