## 结构原理

为什么这样排列？

1. **痛点先行**：小红书用户浏览速度快，前 3 秒决定是否继续阅读。痛点引入能快速筛选目标人群并建立情感连接。
2. **卖点紧随**：在共鸣峰值时给出解决方案，用户接受度最高。
3. **证言托底**：用户对广告天然有防御心理，第三方证言能有效降低信任门槛。
4. **促单收尾**：在兴趣最高时给出行动指令，转化率最优；过晚则用户注意力已流失。

## 变体

1. **证言前置型**：适合高客单价或信任门槛高的品类，先用权威背书打开局面，再引入痛点。
2. **痛点强化型**：适合痛点极其明确的刚需品，可用 2 个段落层层递进放大痛点，再给出解决方案。
