## 示例 1：化妆品极限词 + 医疗宣称 + 站外导流 + 诱导好评（淘宝）

**输入**（`examples/input.json`）：

```json
{
  "platform": "淘宝",
  "category": "化妆品",
  "text": "【全网最低价】医美级精华液，100%彻底淡化痘印，效果最好的抗敏修复神器！国家级实验室研发，独家配方，销量第一。好评返现 5 元，加微信 xxx 领试用装，扫码进群。比 XX 大牌好用，专利配方，纯天然无添加，本品适用于各类肌肤，无任何副作用。"
}
```

**输出**（实跑，命中 18 项，判定：不建议上架）：

| 级别 | 代表命中 | 命中规则 | 修改建议 |
|---|---|---|---|
| 🔴 红线 | 最低 / 100% / 彻底 / 最好 | 绝对化用语 | 改具体描述或注明数据来源 |
| 🔴 红线 | 医美级 / 抗敏 | 化妆品·医疗宣称 | 删，改「舒缓保湿」 |
| 🔴 红线 | 国家级 / 独家 / 第一 | 绝对化·级别/唯一性/排名 | 删除；有专利附专利号 |
| 🔴 红线 | 好评返现 | 诱导评价 | 删返现话术 |
| 🔴 红线 | 加微信 / 扫码 | 淘宝·站外导流 | 删导流信息 |
| 🔴 红线 | 比 XX 大牌好 | 贬低竞品 | 改客观参数对比 |
| 🟡 警告 | 全网最低 / 专利配方 | 虚假促销 / 专利虚标 | 注明活动时间 / 补专利号 |
| 🔵 提示 | 纯天然 / 无添加 | 无添加宣称 | 补检测报告编号 |

**整改后文案**（可直接用）：

> 2026 年新款精华液，限时优惠价 ¥99。配方含神经酰胺与透明质酸，主打舒缓保湿。
> 实测反馈良好（样本 30 人）。

## 示例 2：食品功效宣称（抖音）

**输入**：

```json
{
  "platform": "抖音",
  "category": "食品",
  "text": "古法熬制红糖，补血养颜，暖宫驱寒，女生必备，纯天然无添加，喝了气色好。"
}
```

**输出**（实跑）：
- 🔴「补血」「养颜」→ 食品·疾病治疗宣称（《食品安全法》第 73 条）
- 🔵「纯天然」「无添加」→ 需检测报告支撑

**整改后文案**：

> 古法熬制红糖，传统工艺，口感醇厚。冬季冲饮常备。（检测报告编号：XXX）

## 示例 3：教育 / 金融类目（类目禁词表切换）

**输入**：

```json
{
  "platform": "通用",
  "category": "教育",
  "text": "保过班，名师授课，100% 提分，不过全额退费。"
}
```

**输出**（实跑）：🔴「保过」「100% 提分」「名师」→ 教育·效果保证（《广告法》第 24 条）。
把 `category` 换成 `金融` 时，同一段「保本」「稳赚」会命中第 25 条——**类目词表按 `category` 切换**，
不填 category 则只扫绝对化用语与通用不正当竞争规则。

## 示例 4：假阳性对照（这些不该报违规）

**输入**：

```json
{
  "platform": "淘宝",
  "category": "",
  "text": "最新款 iPhone 17 手机壳，正面全包边。很多顾客说第一眼就喜欢这个配色。316L 医用级不锈钢卡扣。"
}
```

**输出**（依 prompt 的假阳性拦截规则）：

| 表述 | 处理 |
|---|---|
| 最新款 iPhone 17 | ✅ 不报（有依据的事实陈述） |
| 第一眼就喜欢 | 🟡 提示（用户主观评价引用），不判红线 |
| 316L 医用级不锈钢 | ✅ 不报（材料牌号，非功效宣称） |
