# 使用示例

以下示例的输入均为**真实可跑数据**，校验结果由 `scripts/detail_page_outline.py` 实跑产生。

---

## 示例 1：Amazon A+ 页面 · 8 模块全过（本技能主场景）

**输入**（`examples/input.json`）：保温杯 A+ 页面，8 个模块 + 本店 3 款 SKU 对比表。

**输出**（实跑）：模块数 8 ✅、A+ 必备模块齐全 ✅、首屏 112 字 ✅、
模块文案无违禁 ✅、对比表无竞品贬低 ✅ —— **5/5 全过，0 项待整改**。

**要点**：对比表只列本店 500ml / 350ml / 700ml 三款，逐项参数中立可验证，
不出现任何竞品品牌名。

---

## 示例 2：对比表写竞品（违规，脚本拦截）

**输入**（在示例 1 基础上改对比表）：

```json
{
  "sku_table": [
    {"参数": "保温时长（比XX品牌好）", "本店 500ml 保温款": "12h，碾压同行"},
    {"参数": "内胆材质", "本店 500ml 保温款": "304 不锈钢"}
  ]
}
```

**输出**（实跑）：对比表红线 🔴 命中 3 处 ——
「同行」（提及竞品）、「比XX品牌好」（贬低竞品）、「碾压」（贬低竞品），
校验 3/5 通过，待整改 1 项。

**整改前 → 整改后**：

| ❌ 整改前 | ✅ 整改后 |
|---|---|
| 保温时长（比XX品牌好）：12h，碾压同行 | 保温时长：12h（实验室口径） |

> 对比表**只准写本店 SKU 之间的差异**，且差异表述必须中性、可验证
> （《反不正当竞争法》第十一条商业诋毁）。

## 示例 3：模块数与首屏字数越界

**输入**：

```json
{
  "modules": [
    {"模块": "主图区", "建议字数": 80},
    {"模块": "痛点共鸣", "建议字数": 120},
    {"模块": "卖点图文", "建议字数": 60},
    {"模块": "售后承诺", "建议字数": 30}
  ]
}
```

**输出**（实跑）：
- 🔴 模块数 4 < 6，信息不足
- 🔴 A+ 必备模块缺失（缺品牌故事 / 对比表 / 场景图）
- 🟡 首屏（前 3 模块）字数 260 > 120

**整改方向**：补足到 6–10 个模块，并把参数类内容后移到规格表，
使前 3 屏总字数 ≤ 120。

## 示例 4：模块文案夹带绝对化用语

**输入**：

```json
{
  "modules": [
    {"模块": "主图区", "建议字数": 12, "文案": "全网最低价 MUGGO 保温杯"},
    {"模块": "痛点共鸣", "建议字数": 48, "文案": "办公室一杯热茶常喝常凉。"},
    {"模块": "卖点图文", "建议字数": 52, "文案": "304 不锈钢内胆 + 真空层，12 小时保温。"}
  ]
}
```

**输出**（实跑）：🔴 模块文案命中「最低」→ 绝对化·最高级，
待整改项「模块文案含违禁词，须先过广告法预审」。

**整改后**：

> 限时优惠价 ¥99 · MUGGO 不锈钢真空保温杯（12 小时保温）
