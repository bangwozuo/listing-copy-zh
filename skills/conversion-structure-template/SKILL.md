# 转化结构模板

把卖点搭成**模块化、可排版、可交付美工**的详情页 / A+ 页面骨架，
给每个模块标明功能定位、字数与素材要求。

不做的事：不写卖点本身、不写标题、不做合规终审。只交付**结构与模块清单**。

## 元信息

| 类型 | **`atomic`（原子技能）** |

## 能力描述

1. **模块库** —— 主图区、痛点共鸣、卖点图文、品牌故事、对比表、场景图、规格表、
   FAQ、包装清单、售后承诺，共 10 个标准模块。
2. **排序逻辑** —— 异议前置、证据后置、信任模块中后段、移动端前 3 屏独立成立。
3. **对比表红线** —— 只对比本店 SKU，禁写竞品品牌名与贬低话术。
4. **五项校验** —— 模块数 6–10 / A+ 必备模块 / 首屏 ≤ 120 字 / 对比表无竞品贬低 /
   模块文案无绝对化与导流。

## 输入规格

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `brief` | object | ✅ | 品类、核心卖点、目标人群、品牌名、本店 SKU 列表 |
| `platform` | string | ⬜ | Amazon（A+）/ 淘宝 / 天猫 / 抖音 / 拼多多 / 小红书 |
| `selling_points` | array | ⬜ | 已有卖点清单（无则按 brief 归纳） |
| `competitor` | string | ⬜ | 竞品名（**仅用于提示规避**，不得写入成品） |

## 输出规格

- `modules`：模块结构表（模块 / 功能定位 / 建议字数 / 素材状态 / 补齐动作）
- `structure_map`：对比表设计（仅本店 SKU 的参数矩阵）
- `checks`：五项校验结果
- `issues`：待整改清单

## 使用步骤

### 方式一：纯提示词（最快）

1. 打开任意 AI 工具（Coze / WorkBuddy / Dify / Claude / ChatGPT）
2. 把 `prompt.txt` **全文**粘贴为系统提示词
3. 提供 `brief`（可选 `platform`）
4. 得到模块结构 + 对比表设计 + 校验表

### 方式二：带脚本（结构规则校验 + 产出 Excel）

```bash
python3 <SKILL_DIR>/scripts/detail_page_outline.py --input input.json --outdir out
python3 <SKILL_DIR>/scripts/detail_page_outline.py --demo      # 无输入也能看效果
```

产物：

| 文件 | 内容 |
|---|---|
| `out/详情页结构.xlsx` | 模块结构 / 对比表 / 校验 / 汇总 |
| `out/detail_page.json` | 机器可读结果 |

**分工**：脚本做**结构规则校验**（模块数、必备模块、首屏字数、对比表红线）；模型做**模块创意与文案**。

## 边界（不做的事）

- ❌ 对比表出现竞品品牌名或贬低性话术
- ❌ 编造素材内容或参数（容量、材质、检测数据须来自 `brief`）
- ❌ 模块数 < 6 或 > 10
- ❌ 在详情页写站外导流（二维码、微信号）

## 调用示例
