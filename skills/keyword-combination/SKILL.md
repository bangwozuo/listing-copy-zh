# 关键词组合

把一个商品的类目词、属性词、场景词、长尾词，按目标平台的**搜索权重规则**组合成
可被检索、可被点击、不违规的**标题候选**，并给出关键词的三处落位表。

不做的事：不写详情页文案、不写促销方案、不判断商品质量。

## 能力描述

1. **平台字数硬约束** —— 淘宝/天猫/拼多多 60 字符、抖音 30 字、小红书标题 20 字、
   Amazon 200 字符；超限即不合格。
2. **位置即权重** —— 标题骨架 `核心词 → 属性词 → 场景词 → 长尾词`，核心词必须落在前 10 字符。
3. **关键词三层 + KD 值** —— 核心词（必争）、长尾词（KD ≤ 0.5）、蓝海词（KD ≤ 0.2），
   蓝海词不进标题、只进卖点与详情页。
4. **五项校验** —— 每个标题候选跑「字数 / 核心词前置 / 无重复词 / 无无关词 / 无违禁词」。

## 输入规格

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `product_info` | object | ✅ | 商品信息：品名、材质、规格、卖点、适用人群/场景 |
| `platform` | string | ✅ | 淘宝 / 天猫 / 抖音 / 拼多多 / 小红书 / Amazon |
| `keywords` | array | ⬜ | 已知关键词及层级（无则模型按类目推断并标「待补数据」） |
| `candidate_titles` | array | ⬜ | 已有标题（有则只做校验，不重新生成） |

## 输出规格

- `title_candidates`：3 个候选（类目流量型 / 精准长尾型 / 场景覆盖型），每个含字数与占上限比
- `keywords`：关键词布局表（层级 / KD 区间 / 建议位置 / 出现次数）
- `checks`：五项校验结果（每个候选一行）
- `pending_data`：需用户从后台补的数据项（KD、搜索量）

## 使用步骤

### 方式一：纯提示词（最快）

1. 打开任意 AI 工具（Coze / WorkBuddy / Dify / Claude / ChatGPT）
2. 把 `prompt.txt` **全文**粘贴为系统提示词
3. 提供 `product_info` + `platform`（可选 `keywords`）
4. 得到标题候选 + 关键词布局 + 校验表

### 方式二：带脚本（字数与违规词精确校验 + 产出 Excel）

```bash
python3 <SKILL_DIR>/scripts/title_keyword_check.py --input input.json --outdir out
python3 <SKILL_DIR>/scripts/title_keyword_check.py --demo      # 无输入也能看效果
```

产物：

| 文件 | 内容 |
|---|---|
| `out/标题关键词校验.xlsx` | 标题候选校验 / 关键词布局 / 汇总 |
| `out/keyword_check.json` | 机器可读结果，供智能体读取 |

**分工**：脚本做**字数、位置、重复、动词命中的精确计算**；模型做**词分层与语义判断**。

## 边界（不做的事）

- ❌ 不编造 KD 值、搜索量、竞品数据 —— 缺数据就标「待补数据」
- ❌ 不写蹭流量词、不堆核心词、不做词元内耗
- ❌ 不写入未获授权的品牌词
- ❌ 不替代平台后台的关键词工具，本结果是**组合建议**而非流量承诺

## 调用示例

**输入**（`examples/input.json`）：

```json
{
  "platform": "淘宝",
  "product_info": {
    "品名": "304 不锈钢真空保温杯",
    "材质": "304 不锈钢内胆 + 316 不锈钢外壳",
    "规格": "500ml / 杯高 21cm",
    "卖点": ["12 小时保温", "带茶隔", "杯盖密封不漏"],
    "场景": ["办公室", "通勤", "车载"]
  },
  "keywords": [
    {"词": "保温杯", "层级": "核心词"},
    {"词": "带茶隔保温杯", "层级": "长尾词"},
    {"词": "大容量女款", "层级": "长尾词"}
  ]
}
```

**输出**（脚本实跑）：见 `examples/output.md`。淘宝上限 60 字符，主推候选 24 字符，
核心词「保温杯」落在第 1 字符，五项校验全过。
