### 示例 1：关键词组合

**能力**：类目词×平台规则→标题

**输入**：

```json
{
  "product_info": {
    "名称": "冰丝防晒衣",
    "材质": "锦纶 + 氨纶",
    "卖点": [
      "UPF50+",
      "可拆卸帽檐"
    ]
  }
}
```

**输出**：

## 优化后标题

夏季冰丝防晒衣 男女同款 轻薄透气 UPF50+ 防晒外套 可拆卸帽檐

## 卖点清单

1. **UPF50+ 硬防晒** — 可提供检测报告编号
2. **冰丝凉感材质** — 锦纶 + 氨纶混纺，客服可提供成分表
3. **可拆卸帽檐** — 一衣两穿，通勤与户外通用

## 合规扫描

- 结论：**通过**
- 违规词：无（已规避「最好」「第一」「国家级」等极限词）

**资产位置**：`skills/keyword-combination/`

### 示例 3：广告法合规预审

**能力**：广告法违禁词检测

**输入**：

```json
{
  "text": "全网最低价，包治百病，100% 有效"
}
```

**输出**：

## 扫描结果

**结论**：不通过

## 违规项

| 位置 | 原文 | 问题类型 | 修改建议 |
|------|------|---------|---------|
| 第 1 句 | 全网最低价 | 极限词 | 改为「同价位中较有优势」 |
| 第 1 句 | 包治百病 | 虚假功效 | 删除，改为具体适用场景描述 |
| 第 1 句 | 100% 有效 | 绝对化表述 | 删除，改为「多数用户反馈良好」 |

## 风险等级

**高** — 同时命中三类违规，直接发布可能被平台处罚

## 补充建议

建议补充 AI 生成内容标识；如涉及功效描述，需提供检测报告支撑。

**资产位置**：`skills/adlaw-compliance-precheck/`
