### 失败处理路径验证

| 场景 | 触发方式 | 实测行为 |
|---|---|---|
| `text` 缺失 | 只传 `platform` | 第 1 步 ❌ 中止「缺字段: text」 |
| 未给整改稿 | 不传 `revised_text` 且初检有红线 | 第 3 步 ⏭ 跳过，第 4 步交付「待整改」 |
| 初检即通过 | 传母婴合规文案 | 第 2 步 ✅，第 3 步 ⏭ 跳过（无需复扫） |
| 复扫仍有红线 | 整改稿仍含违禁词 | 退回再改，复扫上限 2 次后中止 |
| 技能脚本缺失 | 重命名 `skills/` 下脚本 | 抛 `FileNotFoundError`，流程中止 |

## 四、边界与已知限制

| 限制 | 说明 |
|---|---|
| 复扫为脚本内去词模拟 | 真实场景中整改稿由人工/模型产出；脚本用「删命中字符」模拟再改 |
| 词表非穷尽 | 覆盖高频违规词；长尾与语境判断依赖模型按 prompt.txt 复核 |
| 平台规则时效 | 词表基于公开规范整理，平台更新后需维护 |
| 建议仅初检产出 | 整体修改建议来自初检；复扫只报残留违规 |
