## 四、边界与已知限制

| 限制 | 说明 |
|---|---|
| 模块创意不由脚本生成 | 脚本只校验规则；模块与文案由模型按 prompt.txt 产出 |
| 素材状态依赖输入 | 素材是否已有以 `modules[].素材状态` 为准，脚本不核验实物 |
| 对比表语义 | 「其他品牌」等影射词标 🟡 而非 🔴，须模型按 prompt 复核 |
