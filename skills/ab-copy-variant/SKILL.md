# A/B 文案变体

把**同一个卖点**从不同角度改写成多个**不同质**、**单一变量**、**可做显著性检验**的变体，
并给出 CTR 数据下的择优建议。

不做的事：不写新卖点、不改商品实质信息、不做合规终审。

## 能力描述

1. **6 角度库** —— 理性功能 / 数据实证 / 场景代入 / 情感共鸣 / 疑问钩子 / 对比反差，角度互异。
2. **差异度量化** —— Jaccard 相似度 `J = |A∩B| / |A∪B|`（按字符二字组集合），
   J ≥ 0.6 判同质化，不可用于 A/B。
3. **单一变量原则** —— 一次实验只改卖点表达，价格/主图/时段/类目全部冻结。
4. **样本量与择优** —— 两比例检验 `n ≈ 16·p̄(1-p̄)/Δ²`；样本不足只报值不下结论。

## 输入规格

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `brief` | string | ✅ | 实验需求：测什么、目标平台、目标人群 |
| `selling_point` | string | ⬜ | 被改写的卖点原文（单一卖点，变体只改它） |
| `variants` | array | ⬜ | 已有变体（提供则只做差异度与合规校验） |
| `metrics` | object | ⬜ | 各变体曝光量与点击量，用于显著性判定与择优 |
| `platform` | string | ⬜ | 淘宝 / 天猫 / 抖音 / 拼多多 / 小红书 / Amazon |

## 输出规格

- `variants`：变体组（角度 / 文案 / 字数 / 上限 / 结论）
- `similarity_matrix`：两两 Jaccard 差异度矩阵
- `checks`：五项校验（变体数 / 角度互异 / 无同质化 / 字数合规 / 无违禁词）

## 使用步骤

### 方式一：纯提示词（最快）

1. 打开任意 AI 工具（Coze / WorkBuddy / Dify / Claude / ChatGPT）
2. 把 `prompt.txt` **全文**粘贴为系统提示词
3. 提供 `brief` + `selling_point`（可选 `metrics`）
4. 得到变体组 + 差异度矩阵 + 实验设计

### 方式二：带脚本（差异度与样本量精确计算 + 产出 Excel）

```bash
python3 <SKILL_DIR>/scripts/variant_matrix.py --input input.json --outdir out
python3 <SKILL_DIR>/scripts/variant_matrix.py --demo      # 无输入也能看效果
```

产物：

| 文件 | 内容 |
|---|---|
| `out/AB变体矩阵.xlsx` | 变体组 / 差异度矩阵 / 实验设计 / 校验 |
| `out/variant_matrix.json` | 机器可读结果 |

**分工**：脚本算**相似度与样本量**（数学部分）；模型做**角度选择与变体撰写**。

## 边界（不做的事）

- ❌ 变体只做同义换词（J ≥ 0.6 仍标可用）
- ❌ 一次实验同时改价格、主图、时段等多个变量
- ❌ 样本不足仍下「A 版更好」的结论
- ❌ 编造 CTR、曝光量、转化率数据

## 调用示例

**输入**（`examples/input.json`）：淘宝标题「12 小时保温」卖点，4 个角度变体 + CTR 数据。

**输出**（脚本实跑）：4 个变体全部 Jaccard < 0.6（同质化对 0）；每组最小曝光 1900，
实际曝光约 2400/组 → 样本充足；B 版 CTR 高 2.1pp → 建议采用 B。
