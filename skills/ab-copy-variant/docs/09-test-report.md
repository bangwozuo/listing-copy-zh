## 四、边界与已知限制

| 限制 | 说明 |
|---|---|
| 相似度口径 | 用字符二字组集合，非语义向量；语义同义但用词迥异的变体可能 J 偏低（须模型复核） |
| p̄ 与 Δ | 无历史数据时用经验值，脚本会标注「经验值」，不得当实测引用 |
| 显著性 | 用近似样本量公式，非精确两比例检验（z 检验/卡方）；如需严格结论请用统计工具 |
| 数据来源 | 脚本不采集任何用户数据；`metrics` 由用户从平台后台导出 |
