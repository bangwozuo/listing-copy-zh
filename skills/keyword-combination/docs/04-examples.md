## 示例 1：淘宝保温杯 · 4 个候选含 1 个违规（本技能主场景）

**输入**（节选自 `examples/input.json`）：

```json
{
  "platform": "淘宝",
  "core_word": "保温杯",
  "product_info": {
    "品名": "304 不锈钢真空保温杯",
    "规格": "500ml / 杯高 21cm",
    "卖点": ["12 小时保温", "带茶隔", "杯盖密封不漏"],
    "场景": ["办公室", "通勤", "车载"]
  },
  "candidate_titles": [
    "保温杯 304不锈钢 500ml 办公室便携带茶隔",
    "2026新款保温杯大容量办公室学生便携水杯不漏水焖烧杯",
    "全网最低价保温杯 100%保温 销量第一 独家304不锈钢"
  ],
  "category_words_to_avoid": ["手机壳", "数据线", "充电宝"]
}
```

**输出**（实跑）：4 个候选中 3 个可用；第 4 个被脚本命中 4 处违禁词
（`最低`/`100%`/`第一`/`独家`），判定「需修改」。

**整改前后对照**：

| | 标题 | 结论 |
|---|---|---|
| ❌ 整改前 | 全网最低价保温杯 100%保温 销量第一 独家304不锈钢 | 🔴 违禁词 4 处 |
| ✅ 整改后 | 保温杯 304不锈钢 500ml 办公室便携 焖烧保温 | 五项全过 |

## 示例 2：抖音字数红线（30 字 vs 淘宝 60 字符）

**输入**：

```json
{
  "platform": "抖音",
  "core_word": "保温杯",
  "candidate_titles": [
    "304不锈钢真空保温杯500ml大容量办公室便携带茶隔学生水杯",
    "保温杯 500ml 带茶隔"
  ]
}
```

**输出**（实跑）：抖音标题按**汉字个数**计、上限 30 字。
第 1 条 27 字 → ✅ 合规；第 2 条 12 字 → ✅ 合规。
把同一个标题换到 `platform = 小红书`（上限 20 字）时，第 1 条立即变 🔴 超限——
这就是「跨平台同一标题不可直接复用」的量化证据。

## 示例 3：核心词未前置（结构不合格）

```json
}
```

**输出**（实跑）：核心词「保温杯」落在第 14 字符 > 阈值 10 → 🟡「未前置」，
结论「需修改」。脚本给出的整改写法：把核心词提到句首——

> 保温杯 2026新款大容量办公室学生水杯

## 示例 4：蹭流量词拦截（对照组）

**输入**：

```json
{
  "platform": "淘宝",
  "core_word": "保温杯",
  "candidate_titles": ["保温杯 手机壳 数据线 三件套"],
  "category_words_to_avoid": ["手机壳", "数据线", "充电宝"]
}
```

**输出**（实跑）：命中 2 个无关类目词 → 🔴「蹭流量词」，结论「需修改」。
平台会将此类标题判为「标题不符」，规则不支持跨类目堆词。
